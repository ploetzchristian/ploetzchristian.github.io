Mein Server n8n

Diese Anwendung ist eine private Automatisierung von Christian Plötz. Sie läuft auf einem privaten Server mit n8n und wird ausschließlich vom Betreiber selbst genutzt.

Zweck: Kursunterlagen werden wöchentlich aus einem Google-Drive-Ordner in das eigene Google Drive kopiert. Ausgewählte Personen erhalten Lesezugriff und eine Benachrichtigung per E-Mail.

Die Anwendung wird nicht öffentlich angeboten. Es gibt keine Registrierung für Dritte.
